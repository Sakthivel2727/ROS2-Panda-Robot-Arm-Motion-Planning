**ROS 2 Panda Robot Arm Motion Planning**

**Project Overview**

This project demonstrates motion planning of a Franka Emika Panda robot arm using ROS 2 Humble, MoveIt 2, and RViz.

The robot is programmed to move through predefined poses while using motion planning to generate a collision-free path.

**Objectives**
Set up a ROS 2 workspace for robot arm motion planning.
Control the Panda robot using MoveIt 2.
Plan and execute robot arm movements.
Visualise the robot and planned trajectory in RViz.
Add objects to the planning scene and avoid collisions.

**Software Used**
Ubuntu 22.04
ROS 2 Humble
MoveIt 2
RViz 2
Python
Git and GitHub

**Robot**
Franka Emika Panda robotic arm.

**Motion Sequence**
The planned motion sequence is:
Home → Pose 1 → Pose 2 → Home

The robot generates a motion trajectory between the target poses using MoveIt 2.
